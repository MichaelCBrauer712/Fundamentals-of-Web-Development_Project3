# Fundamentals of Web Development, Project 3

A four page site built on the Project 2 pages, with media queries and JavaScript added.

## Pages
- index.html: resume, fixed width layout
- volleyball.html: fluid layout, mobile first with two min-width media queries
- soccer.html: fluid layout
- map.html: Google Map of Naples, Florida

## Styling
- css/reset.css: reset styles
- css/style.css: all site styles
- Imported font: Playfair Display (Google Fonts) for headings
- Native font: Arial for body text
- Relative units (rem, %) for fluid pages, px only for maximum widths

## JavaScript
- js/script.js is linked from the head of every page and loads with defer
- Shows today's date in the footer of every page
- Map page features added to the base map: a marker with an information window, map and satellite view buttons, and click to drop pins with a counter and a clear button
